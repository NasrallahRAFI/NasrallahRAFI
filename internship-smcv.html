PFA Internship: Industrial Automation Project (PLC/HMI)

**Company:** SMCV (Société Marocaine des Compteurs) | **Duration:** July 2025 – September 2025

#PLC #TIA Portal #HMI Development

Overview and Goal

The primary objective of this final-year project was to fully automate the control and monitoring of a pneumatic press and mechanical arm system used in injection molding. This involved integrating a modern Siemens S7-1500 PLC and developing an intuitive Human-Machine Interface (HMI) for operators.

Technical Execution

  • **PLC Programming (TIA Portal):** Developed structured ladder logic and Function Block Diagram (FBD) code for sequential control of the mechanical arm movements, pneumatic press cycles, and safety interlocks. Optimized cycle time by 15%.

  • **HMI Design:** Created comprehensive HMI screens (using Siemens Comfort Panel) for real-time visualization of machine status, alarm management, recipe selection, and manual control modes, significantly improving operator feedback.

  • **System Integration:** Successfully interfaced the PLC with various sensors (proximity, pressure) and actuators (solenoid valves, motor drives) to ensure seamless and reliable operation.
